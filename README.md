# fourfourfour spirituality — landing page

React + Vite + Tailwind + Framer Motion.

    npm install
    npm run dev      # local preview
    npm run build    # production build in /dist (upload to Netlify, Vercel, etc.)

WhatsApp number is set at the top of src/App.jsx (const WHATSAPP). Products, prices and text are in the PRODUCTS, SERVICES and PLANS arrays.
Photos live in public/images.
